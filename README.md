
# AI コード生成チャットボット

AIチャットボットとコード生成機能を備えた TypeScript/JavaScript プロジェクトです。

## 機能

- ✨ **チャットボット機能** - 自然言語での対話
- 🚀 **コード生成** - プロンプトからコードを自動生成
- 🌍 **マルチ言語対応** - JavaScript, TypeScript, Python, Java, Go, Rust, C++, C# をサポート
- 📝 **会話履歴管理** - 過去の会話を保持

## サポート言語

- JavaScript
- TypeScript
- Python
- Java
- Go
- Rust
- C++
- C#

```bash
# リポジトリをクローン
git clone https://github.com/landorengou/ai-code-generator-chatbot.git
cd ai-code-generator-chatbot
